# TRC — The Roots Concept website

Responsive café website demo built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. All supplied image assets are stored locally in `assets/`.

## Customize
- Update café details, hours, menu and prices in `index.html`.
- Replace photos in `assets/` if the café supplies higher-resolution originals.
- The Google Maps directions button uses a Maps search URL for TRC in Djibouti.
